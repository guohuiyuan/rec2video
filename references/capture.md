# 录屏怎么录

不用追求完美素材，但下面三条踩了就得重录。

## 三条硬要求

1. **16:9，宽度 ≥ 1920**。1080p 是底线；2560×1440 录屏推镜时不糊。手机竖屏另说（见文末）。
2. **录之前把窗口定死**，中途别改大小、别拖窗口。窗口一动，crop 就废了。
3. **只要干净画面**：不要提前加背景、圆角、阴影、缩放。画框、投影、推镜由 `render.py` 统一加，素材里再套一层就是"画中画里还有一层边框"。

## Recordly（Windows，最省事）

[Recordly](https://github.com/webadderallorg/Recordly) 是开源的录屏 + 剪辑一体工具（AGPL-3.0）：录完能直接在里面套背景、改圆角阴影、修光标、加点击波纹，导出 MP4/GIF。

两种用法，别混：

| 目的 | 怎么做 |
|---|---|
| 就想快速出个片子 | 直接在 Recordly 里做完导出，不用这套流水线 |
| 交给 `rec2video` 做（加旁白/字幕/推镜/BGM） | **导出未加背景的原始画面**（或直接用它的录制文件），背景和圆角留给后期 |

素材给了后期还带背景，成片会出现"框里再套一个框"，返工只能重录。

## OBS（跨平台，参数可控）

- **来源**：`显示器采集`（录整屏，含任务栏）或 `窗口采集`（只录浏览器）。窗口采集更省事——任务栏和别的窗口不会入镜。
- **输出**：1920×1080 或 2560×1440，**30fps 够用**（更高帧率渲染时会降到 30，白占空间）。
- **编码**：NVENC 或 x264，CQP/CRF **18–20**，容器 `mp4`。
- **鼠标**：保持可见。观众要看的就是"你点了哪"。
- **收尾**：操作做完立刻停，尾巴上十几秒空转会被算进画面长度。

## 系统录屏

- Windows：`Win+Alt+R`（Xbox Game Bar，录当前窗口）
- macOS：`⇧⌘5`
- 帧率码率不可控，但流水线不挑格式，能出 ffmpeg 认的 mp4 就行。

## 录多长

| 时长 | 走哪条路 | 说明 |
|---|---|---|
| ≤ 150s | **直出模式**（默认） | 整段画面按旁白总长做拉伸对齐，`stretch` 应落在 0.95–1.05；超出说明文案和画面长度差太多 |
| > 150s | **精剪模式** | `new` 会自动生成联系表；挑十几段有用画面，`plan` + `cut` 按旁白反剪，`stretch` 能压到 1.0000 |

宁可录 3 分钟里挑 70 秒，也不要为了"一次录对"反复 NG——挑素材比重录快。

## 竖屏 / 手机录屏

- crop 出 9:16 后，画框尺寸要跟着改（如 `540×960`），不要硬塞进 16:9 画框——两侧会是大片背景。
- 竖版封面用 `assets/templates/hero.html`，横版用 `repo-page.html`。

## 录完第一步

```bash
python scripts/rec2video.py new <录屏文件> --repo https://github.com/owner/repo
```

它会打完整体检、生成带**原片绝对时间**的联系表 `scan/sheet_*.jpg`。后面所有取材点都从这张表上读秒数。
